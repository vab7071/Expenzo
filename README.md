# Expenzo 💰

Personal Finance Manager built using Flask, SQLite, Bootstrap and Chart.js.

## Features

- User Registration & Login
- Add/Edit/Delete Transactions
- Income & Expense Tracking
- Expense Analytics Dashboard
- Pie Chart Visualization
- Search Transactions
- CSV Export

## Tech Stack

- Python
- Flask
- SQLite
- Bootstrap 5
- Chart.js
- HTML/CSS

## Installation

```bash
git clone https://github.com/vab7071/Expenzo.git

cd Expenzo

pip install -r requirements.txt

python3 app.py
```

## Usage

Open your browser and visit:

```text
http://127.0.0.1:5000
```
